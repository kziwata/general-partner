# 2026-07-02 — 季節変動を考慮した機械波形の異常検知アプローチ整理

## 目的

機械の動作ごとに収集した数秒間の波形データに対し、季節性による変動を踏まえた
異常検知モデルのアプローチを整理し、学習の道筋を立てる。

## 議論の要点

### 問題の捉え方

- 動作単位のスニペットデータでは、季節性は古典的な時系列分解(STL 等)ではなく、
  **正常データの分布が季節でドリフトする分布シフト(ドメインシフト)問題**として扱う。
- DCASE Challenge Task 2(機械音の教師なし異常検知)が 2022 年以降この設定を
  「ドメイン汎化」として標準課題化している。

### アプローチ 4 系統

| 系統 | 内容 | 手法例 | 主な前提 |
|------|------|--------|----------|
| A. 条件付きモデル | 季節・温度等の共変量を入力に加え「その条件下の正常」を学習 | CVAE、条件付き Normalizing Flow、共変量回帰の残差 | 環境データが波形と紐づいている |
| B. 季節別モデル | 季節/条件ごとに正常モデルを分ける、混合モデル | 月別 GMM / kNN / AE、混合ガウス | 各季節に十分な正常データ(実質1年分以上) |
| C. 不変表現学習(主流) | 環境が変わっても変わらない特徴空間で距離ベース判定 | 事前学習音響モデル(BEATs/EAT/HuBERT)埋め込み + kNN、ArcFace 系補助分類、局所密度によるスコア正規化 | スペクトログラム化できる波形 |
| D. 運用で追従 | 適応しきい値・再学習でドリフトに追従 | 移動窓分位点しきい値、定期再学習、ドリフト検知指標 | 緩慢な劣化を正常と学習するリスク管理が必要 |

### 推奨ロードマップ

1. **EDA**: log-mel / 統計特徴を UMAP 等で月別色分けし、季節ドリフトの実態と対象特徴を確認
2. **ベースライン**: log-mel + AE(DCASE ベースライン)または事前学習埋め込み + kNN。
   評価は必ず**季節をまたぐ時系列分割**(ランダム分割は季節性の影響を過小評価)
3. 季節誤検知が出たら C(ドメイン汎化 + スコア正規化)を導入、運用は D(適応しきい値)を併用

## 追記(同日): データは圧力波形と判明 → 軽量構成に絞り込み

- 圧力波形は滑らかで低次元なプロファイル曲線。深層音響モデル(C 案の事前学習系)は不要。
- 圧力は温度と物理的に直結するため、**A 案(共変量補正)が主軸**。
- この問題は SHM(構造ヘルスモニタリング)分野の **EOV 補償(data normalization)** として体系化済み。

### 推奨パイプライン(4段構成)

1. **整列**: 動作トリガー基準で切り出し。動作長が揺れるなら DTW
2. **特徴量抽出**: ピーク圧・立ち上がり時間・整定時間・オーバーシュート・保持圧・圧力積分など
   物理的に意味のある10個前後。曲線全体なら fPCA / PCA スコア
3. **環境変動補正**:
   - 温度計測あり(input-output 法): 特徴量を温度で回帰(線形〜GPR)し残差を異常指標に。本命
   - 温度計測なし(output-only 法): PCA マイナー主成分、または共和分(cointegration)
4. **異常判定**: Mahalanobis 距離(Hotelling T² 管理図)/ GMM / kNN + 分位点しきい値(適応更新)

NN を使うとしても比較用の小さな 1D-conv AE を1本まで。

### 学習トピック(優先順)

1. 多変量統計的異常検知(Mahalanobis、Hotelling T²、GMM)— 井手剛『入門 機械学習による異常検知』
2. 回帰による環境補正(残差分析、非線形なら GPR)
3. PCA / fPCA(マイナー主成分による環境トレンド除去)
4. 共和分(環境データがない場合)
5. DTW(動作長が揺れる場合のみ)

## 追記(同日): 特徴量候補と PCA による季節性補正の詳細

### 圧力波形の特徴量候補(局面別)

| 局面 | 特徴量 | 感度が高い故障モード |
|------|--------|--------------------|
| 立ち上がり | 立ち上がり時間(10→90%)、最大勾配 dP/dt、ピーク到達時間、応答遅れ | 詰まり、バルブ動作不良、駆動系劣化 |
| ピーク・過渡 | ピーク圧、オーバーシュート率、整定時間、リンギング振幅・回数 | 制御系異常、共振変化 |
| 保持(定常) | 保持圧平均、**保持区間の傾き(リーク指標)**、リップル振幅・標準偏差 | シール劣化、リーク |
| 立ち下がり | 減衰時間・勾配、残圧 | 排気経路詰まり、バルブ閉不良 |
| 全体 | 圧力積分値、RMS、レンジ、歪度・尖度、低周波スペクトルパワー | 総合的な状態変化 |
| 曲線全体 | 波形 PCA / fPCA の上位スコア | 手設計で拾えない形状変化 |

推奨構成: 手設計 10〜15 個 +(必要なら)波形 PCA スコア数個。
故障モードから逆算して特徴量を対応付けておくと異常の解釈がしやすい。

### PCA による季節性補正(マイナー主成分法)

**考え方**: 環境要因(温度)は多くの特徴量を相関を持って同時に動かす → 正常データの
上位主成分に集約される。故障は正常の相関構造から外れる方向に出る。
→ 上位主成分を捨て、マイナー成分での逸脱(再構成残差)だけを監視する。

**手順**:

1. 正常データで z-score 標準化(訓練データが季節変動をカバーしていることが必須)
2. PCA を学習
3. 捨てる主成分数 k の決定: 累積寄与率 90〜95%、または
   **各主成分スコアを月・温度に対してプロットし、季節パターンのある成分だけ捨てる**(推奨)
4. 異常スコア: SPE(Q統計量)= ‖x − PkPkᵀx‖²(マイナー成分の Mahalanobis 距離でも可)
5. しきい値: 検証用正常データの分位点。季節をまたいでスコアが安定するか確認

**注意点**:

- 線形仮定。温度影響が非線形なら残差に漏れる → カーネル PCA か回帰補正へ
- 故障が上位主成分と同じ方向に出ると見えなくなる → 温度計測があれば回帰補正と併用が安全
- 季節カバレッジ不足の初年度は適応しきい値で凌ぎ、1年分たまったら再学習
- 類似手法: 共和分(定常性基準で結合を選ぶ。非定常ドリフト除去に強い)

## 決定事項

- 圧力データの特性から、大規模モデルは採用しない。
  「特徴量エンジニアリング + 環境変動補正(EOV 補償)+ 古典的統計手法」を主軸とする。

## 未決事項

- 正常データの蓄積期間 → 季節をまたぐ評価分割の設計
- サンプリング周波数と動作長のばらつき → DTW 整列の要否
